# KB01 management API: A implemented; B–E planned

Implemented prefix /api/v1/admin/knowledge-management: taxonomy list/create/detail/impact/aliases/draft edit/version/review/publish/availability/merge/delete/archive; document list/detail/impact/create/initial version/draft metadata and classification edit/new version/validate/review/publish/expiry/supersession/archive/draft delete; hold create/list/release; operation audit history. All mutations are bound to server actor and current operation grants.

Remaining B–E endpoints extend this channel using shared canonical application use cases and extra-forbid DTOs. Document list/search supports server pagination/filter/sort; details/history/diff; version metadata CAS; structured preview. upload-sessions create/parts/resume/complete/abort and capability/policy endpoints; imports create/detail/manifest-preview/resolve-mappings/confirm/cancel/retry; statistics overview/dimension/cross-filter; governance validate/submit-review/approve/reject/publish/archive; deletion-impact/authorized draft delete/restore where policy allows.

Backend owns tenant/actor/object key/target binding/version/time. No caller-supplied authorizer. Upload completion independently streams storage object checksum, size and type; S3 ETag/client hash is not full-object SHA256 authority. Keys are tenant/session scoped and expire; no public URLs. Idempotency same key/payload returns original, changed payload409; CAS stale409; forbidden403 or scoped404; missing adapter503 CAPABILITY_NOT_CONFIGURED. Metadata previews are not final publication.
