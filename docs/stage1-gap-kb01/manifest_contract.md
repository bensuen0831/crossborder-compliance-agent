# Implemented bounded Manifest preview

Application: knowledge_manifest.py, pure proposals and reconciliation. Infrastructure: NativeManifestParser (actual openpyxl XLSX and csv); explicit injected ManifestRowsPort, no provider import in Application. Configurable nine-field header mapping, sheet selection, CSV encoding, size/expanded-size/entry/row/column bounds. Unknown metadata labels require explicit backend-governed mappings; multilingual labels can map to multiple language IDs. No country inference. Case-sensitive NFC path normalization is default; case folding is explicit policy. Reject absolute/UNC/drive/traversal/control-character paths. Match full relative path, retain duplicate basename in different directories, flag duplicate/ambiguous identities, report unlisted and missing files.

No inventory supplied -> MANIFEST_IMPORTED only. Explicit empty inventory -> FILE_MISSING. Matching a path -> FILE_MATCHED, never uploaded/validated/published. Issues are structured row/field/code; no DB writes. XLSX ZIP size/entry, external-workbook/macro, XML entity/DOCTYPE and formula guards. Formula values are never evaluated. Real资料汇总清单.xlsx is NOT PROVIDED; user-reported1026/24/6/5/16 and format totals remain unverified actual-dataset expectations. Synthetic tests do not reproduce1026 records.
