# Canonical Knowledge ingestion

Verified provider-versioned originals are parsed in offline non-root bounded native processes. The neutral native extraction core is shared with the existing Project adapter; no Knowledge ID is disguised as a Project, DocumentVersion or AnalysisSnapshot. Genuine six-format sources, multilingual/RTL text and OCR retain safe excerpts, locator/bbox/confidence and exact original provenance.

Existing KnowledgeIngestionRun, KnowledgeStructureNode, KnowledgeChunk, Citation, Evidence and RegulatoryStructure owners remain authoritative. Parse JSON does not replace the original. Explicit governed scope binding, quality validation, independent review and publication drive the existing publication outbox/index/graph/cache/readiness pipeline. Technical ingestion cannot publish, approve or invent formal legal conclusions.

Human translation alignment pins exact source/target clauses, digests and citations and requires independent review. Translation, language confidence and synthetic fixtures are not official legal evidence.

See [parser matrix](parser_matrix.md), [architecture](architecture_design.md), [database design](database_design.md) and actual binary-ingestion/translation/publication regressions. Real legal acceptance remains separately blocked on external evidence.
