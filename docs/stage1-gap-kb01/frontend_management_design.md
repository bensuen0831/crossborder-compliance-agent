# Knowledge management UI

The existing AdminShell, router, transport, theme and i18next instance host the workspace. Country/jurisdiction hierarchy leads to dynamic regulation categories and document lists. Options, search facets, counts, scope bindings, quality and runtime readiness come from scoped backend projections; no legal taxonomy or count is hardcoded in the UI.

The workspace supports governed taxonomy CRUD/history/impact, local files/folders and archives, resumable multipart progress, optional catalogue preview/mapping, original download, clause/Citation preview, explicit scope binding, validation/review/publication and reload. Backend current grants control allowed operations. pending member scan state remains visible before mapping is available.

zh-CN/zh-HK/en-US share formal codes and canonical identities. Frontend tests retain all original suites; new genuine Browser tests cover six formats in three locales, optional catalogue mapping, country/category lifecycle and four large capacity kinds. Console/HTTP errors remain asserted, with signed credential query data redacted from public evidence. Browser retries stay0.
