## Final requirement audit: bounded bulk operations

The document workspace now exposes page-scoped selection (up to100), dependency/impact preview, exact-version selection for expire/archive, mandatory reason, and per-document partial outcomes. These controls orchestrate the existing canonical DELETE_DRAFT/EXPIRE/ARCHIVE application commands; they introduce no new document, lifecycle or audit authority. Every server command independently enforces current permissions, eligibility, CAS and idempotency. Archive does not silently expire an ACTIVE version. A frozen command retains its payload/idempotency key on network retry, and successful items are not resubmitted. New preview explicitly refreshes exact versions. Clear selection releases the reviewed command set. Three locales share these codes and commands.

The existing SQL sort contract is now selectable in the UI: updated_desc/title_asc/created_desc. Filtered counts still use the same canonical resource scope. A real Browser case deletes two eligible unreferenced drafts and reconciles SQL counts/audit; the real-directory Browser case independently reviews/publishes two native originals and then expires/archives their explicit versions using the batch UI. Test authoring diagnostics (an exact label locator and the canonical DOCUMENT_DELETE_DRAFT audit code) are retained separately; no production assertion or authorization was weakened.

## Statistics completion at the requirement audit

The shared authorized SQL document scope now also projects country×category/topic/language/format/status/source cells, distinct documents per cell, bounded pagination, missing-dimension exclusion and explicit non-additive group semantics. The dashboard separates all-version lifecycle counts and parse-run counts from representative-document language/format groups. Catalogue rows, missing catalogue files, verified uploaded objects and bytes are a separate **tenant operational unfiltered** inventory, visible only with current batch/manifest/upload read grants. They are never described as distinct regulations and are not silently filtered by document labels. No fixture values or sample counts enter production. The published country tree reads the same scoped classification counts; when groups are truncated it does not fabricate tree totals. These are SQL projections over canonical owners, not a second statistics source of truth.

## Single-document deletion follows the same reviewed impact boundary

Single-document Delete now requires an explicit server dependency/retention preview, shows the protected reason and reference counts, and remains disabled for ineligible drafts. A concurrent409 refreshes both the canonical document revision and impact rather than presenting a generic HTTP error as the only explanation. Eligibility remains server-owned and is rechecked transactionally. Bulk completion clears stale detail/action projections while retaining per-item receipts/results. Real Browser acceptance inspects an eligible single document before completing the two-document batch; focused UI cases separately prove protected versus eligible previews. No new server authority, DTO or migration is introduced by this UI completion.
