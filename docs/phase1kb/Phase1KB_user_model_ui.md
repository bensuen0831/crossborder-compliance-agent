The canonical Intake Step3 exposes MINIMAL/STANDARD/ENHANCED and AUTO/SINGLE/MULTI_MODEL preferences. Generated schema enums supply stable values; zh-CN/zh-HK/en-US labels are presentation only. Models come exclusively from the authorized backend eligible catalog. Users cannot configure endpoints, credentials or arbitrary remote model names.

Preferences persist through the canonical versioned Intake and restore after reload. Confirmation pins exact configuration. Changing an already confirmed preference requires a successor Intake/Snapshot. Incomplete or revoked model selection is rejected by the backend; the UI does not authorize invocation or route legal decisions.
