# M2B security boundary result

Every API revalidates current tenant/project/actor/action. Multipart authority fields and duplicate fields are rejected. Size/media/signature/archive/path/hash constraints are server policy; original filename is normalized. Storage keys/tenant/policy/formal conclusions are never supplied as authority by browser. Snapshot history cannot bypass current authorization. Cross-source values use existing ContextConflict/ReviewTask and retain genuine distinct manual/document provenance.
